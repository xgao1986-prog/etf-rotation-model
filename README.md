### v1.2.3 核心更新

#### 1. B0.4 正式冻结基线
- **18只ETF固定池**：16只行业ETF + 黄金ETF(518880.SH) + 国债ETF(511010.SH)
- 动量因子关闭、波动率因子关闭，仅趋势+确认+成交量参与评分
- 每周四调仓，最多5只，单只新建仓上限20%，固定止损-8%
- B0.3因尾部数据缺失（2026-06-08~12）已废止，B0.4为唯一当前对照基线

#### 2. 调仓引擎 v2.5
- 纯函数调仓规划 `plan_rebalance_v2_5`，消除顺序依赖
- 行业ETF优先于防御资产，防御只承接剩余资金和槽位
- 先卖后买，统一分配并计入佣金、整手
- 估值和可交易性分离：缺价持仓不能按零估值

#### 3. 数据准入检查 v1.1
- 回测前自动验证数据完整性、拼接连续性、异常跳变
- 区分已知覆盖不足（权威上市日晚于数据库首日）与异常内部缺口
- 生成带 SHA-256 的数据快照，确保可追溯
- 准入失败（exit_code>=2）时阻止回测

#### 4. 滑点压力测试（稳健性验证）
- 单变量敏感性：0/3/5/10 bp 单边滑点
- 规划阶段使用滑点价计算，确保所有订单可执行，无静默跳过
- 夏普单调递减：0.8816 → 0.8162 → 0.7870 → 0.7154
- 滑点直接成本占NAV差异约34%~45%，其余来自持仓路径变化
- **不改变0bp冻结基线**：滑点结果仅用于稳健性评估，不反向调优参数

#### 5. Paper Trading v0.3 虚拟盘
- `app.py` 新增第 7 个页签“虚拟盘”，含账户总览、创建账户、今日运行、待确认订单、账户详情与策略对比。
- 对比账户自动执行；影子账户生成 PENDING 订单，用户确认后更新状态。
- 数据完整性检查与资金勾稽已通过测试；Playwright 浏览器验收通过。
- 不修改 B0.4 策略、参数或冻结数据；虚拟实盘版本独立于策略版本。
- 完整历史见 `VERSION_HISTORY.md`。

## 快速开始

### 1. 安装依赖

```bash
cd etf_rotation_model
pip install -r requirements.txt
```

### 2. 下载历史数据

**方式A: iFinD数据（推荐，质量更高）**

在Kimi对话中：
```
用iFinD下载ETF历史数据，从2019-06-03开始
```

**方式B: AKShare数据（本地自动）**

```bash
python main.py update --full
```

> 建议：先用方式A获取iFinD数据，再用方式B补充缺失部分。

### 3. 日常数据更新

**iFinD增量更新（Kimi对话）:**
```
更新iFinD数据到最新
```

**AKShare增量更新（本地）:**
```bash
python main.py update
```

### 4. 回测

```bash
# B0.4 基线回测
python scripts/b0_3_baseline.py

# 样本内回测 (2019-2023)
python main.py backtest --sample in --save

# 样本外验证 (2024-至今)
python main.py backtest --sample out --save
```

### 5. 生成交易信号

```bash
python main.py signal --save
```

### 6. 查看状态

```bash
python main.py status
```

### 7. 启动可视化界面

```bash
streamlit run app.py
```

界面包含 7 个顶部页签，其中“虚拟盘”用于 Paper Trading v0.3：
- 创建对比账户或影子账户
- 运行选中账户生成订单与 NAV
- 在“待确认订单”中确认影子订单
- 查看账户详情、净值曲线与策略对比

## 评分体系

### B0.4 生效评分（动量/波动率关闭）

| 维度 | 权重 | 计算方式 |
|------|------|----------|
| 趋势强度 | 30% | 收盘价>20日均线(+15) + >50日均线(+10) + 均线斜率>0(+5) |
| 趋势确认 | 20% | 连续在20日均线之上的天数×4分，最多5天 |
| 成交量 | 15% | 放量上涨(+15) / 放量(+10) / 普通(+5) |
| **动量** | **0%** | **关闭** |
| **波动率** | **0%** | **关闭** |

> B0.4 基线仅使用趋势强度+趋势确认+成交量（共65%），动量和波动率因子关闭。

## 入场/出场条件

### 入场（B0.4 口径）

| 资产类型 | 总评分 | 收盘价条件 | 均线斜率 |
|----------|--------|------------|----------|
| 行业ETF | ≥ 40 | > 20日均线 | > 0 |
| 防御资产 | ≥ 30 | > 20日均线 × 0.98 | > -0.001 |

### 出场（任一满足）

1. 收盘价跌破 20 日均线（信号失效）
2. 单只回撤超过 -8%（硬止损）

## 仓位控制

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `max_holdings` | 5 | 最多同时持有 5 只 |
| `max_position_per_etf` | 20% | 单只新建仓上限 20% |
| `defense_max_holdings` | 2 | 防御资产最多 2 只 |
| `total_max_holdings` | 5 | 总持仓上限 |
| `lot_size` | 100 | 100股整手 |

**满仓机制**：
- 20% 上限 × 5 只 = 100% 行业仓位
- 行业信号不足时，防御资产（黄金+国债）填充剩余槽位
- 实现接近 100% 满仓，避免结构性空仓
