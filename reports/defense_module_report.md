## 关键发现

### 1. 黄金 vs 国债

- **黄金防御全区间夏普**: 0.564，**国债防御**: 0.512
- **黄金防御全区间收益**: 42.82%，**国债防御**: 37.35%
- **黄金防御全区间回撤**: -10.95%，**国债防御**: -11.36%
- **结论**: 黄金防御在全区间表现优于国债防御（夏普更高、收益更高、回撤更小）

### 2. 单防御 vs 双防御

- **双防御全区间夏普**: 0.548，介于黄金(0.564)和国债(0.512)之间
- **双防御样本外夏普**: 1.255，**三者最高**
- **双防御样本外回撤**: -7.57%，**三者最低**（黄金-9.20%，国债-11.36%）
- **结论**: 双防御在样本外（熊市）表现最优，夏普最高且回撤最小

### 3. 样本内 vs 样本外

- **样本内（2019-2023）**: 三种配置夏普都较低（0.087-0.173），说明防御模块在震荡/慢牛环境中贡献有限
- **样本外（2024-2026）**: 三种配置夏普都显著提升（1.11-1.26），防御价值在熊市中凸显
- **结论**: 防御模块的核心价值在于熊市保护，而非牛市增强

### 4. 动态防御比例测试

- **线性插值 vs 阶梯式**: 由于大盘择时信号（market_signal）为离散值（0.2/0.5/1.0），两种模式结果相同
- **波动率增强**: 启用后回撤略有改善（-10.59%→-9.93%），但收益下降（40.93%→38.64%），效果不明显
- **建议**: 当前阶梯式防御比例已足够有效，无需复杂化

## 配置建议

基于测试结果，推荐以下防御配置：

### 推荐方案：黄金+国债双防御

```python
DEFENSE_UNIVERSE = {
    '518880.SH': '黄金ETF',
    '511010.SH': '国债ETF',
}

DEFENSE_ALLOCATION = {
    0.2: 0.50,   # 防御仓位: 50%配防御资产
    0.5: 0.20,   # 半仓: 20%配防御资产
    1.0: 0.00,   # 满仓: 不配防御资产
}
```

**理由**:
1. 样本外夏普最高（1.255），熊市保护最强
2. 样本外回撤最小（-7.57%），风险控制最优
3. 黄金和国债低相关性，组合配置可分散风险

## 风险提示

1. 防御模块在震荡市可能拖累收益（样本内夏普仅0.087）
2. 黄金ETF在极端行情中可能与股票同向波动，无法完全避险
3. 国债ETF受利率政策影响，加息周期可能下跌
4. 历史回测不代表未来表现，需持续监控
