# 板块成交额/成交量领先性验证报告

**生成时间**: 2026-06-17 12:57  
**验证问题**: 板块量能指标是否能预测对应ETF的未来收益？  
**重要声明**: 只做验证，不改策略

---

## 测试指标概览

| 指标 | 定义 | 放量阈值 |
|------|------|----------|
| 1. 5日/20日比率 | 板块成交额5日均值 / 20日均值 | > 1.5 |
| 2. 120日百分位 | 当日成交额在过去120日中的百分位 | > 80 |
| 3. 量价共振 | 板块上涨 + 成交额放大 | 涨幅>0 且 ratio>1.5 |
| 4. 排名变化 | 板块成交额在所有18板块中的排名变化 | 较前20日平均上升>5位 |
| 5. 未来收益 | ETF在信号日后1/3/5/10日的收益 | - |

|--------|------|------|

### 关键观察

- 放量日和未放量日的ETF次日收益几乎完全相同（差异仅 -0.0000）
- 领先相关性均值 +0.0103，远低于有效预测所需的 0.10+ 水平
- 个别板块（软件ETF、云计算ETF、游戏ETF）的领先相关性稍高（0.04-0.07），但大多数板块接近0

## 三、指标3：量价共振（板块涨 + 成交额放大）

### 统计摘要

| 统计项 | 数值 | 说明 |
|--------|------|------|
| 量价共振日平均1d收益 | +0.0035 | 中位数: +0.0000 |
| 仅涨未放量日平均1d收益 | +0.0004 | 中位数: +0.0002 |
| **共振 vs 仅涨差异** | **+0.0031** | 微弱增益 |
| 共振胜率 | 39.4% | 平均 |
| 仅涨胜率 | 46.6% | 平均 |
| 判断 | **量能放大有微弱增益** | 但差异极小，且胜率更低 |

### 关键观察

- 量价共振日ETF次日收益比仅涨未放量高0.31%，但胜率反而更低（39.4% vs 46.6%）
- 这意味着**少数大涨日拉高了平均收益**，但大多数共振日并没有带来正收益
- 半导体ETF、科创芯片ETF、游戏ETF在共振日表现较好，但其他板块一般

## 四、指标4：板块成交额排名变化（跨18板块）

### 统计摘要

| 统计项 | 数值 | 说明 |
|--------|------|------|
| 排名上升日平均1d收益 | -0.0061 | 中位数: -0.0075 |
| 排名下降日平均1d收益 | +0.0082 | 中位数: +0.0082 |
| **上升 vs 下降差异** | **-0.0143** | 排名上升反而差 |
| 领先相关性 | -0.0123 | 中位数: -0.0077 |
| 领先性判断 | **无显著领先性** | 方向为负 |

### 关键观察

- **反直觉发现**：板块成交额排名上升时，对应ETF次日收益反而更差（-0.0061 vs +0.0082）
- 可能原因：板块成交额排名上升时，板块已经经历了一轮上涨，次日出现回调
- 排名下降反而对应ETF收益更好，说明**板块成交热度是反向指标**（追热点的惩罚）

## 七、综合结论

### 五个指标的领先性总结

| 指标 | 领先相关性 | 与ETF未来收益的关系 | 先导价值 |
|------|-----------|---------------------|----------|
| 5日/20日放量比率 | +0.0103 | 几乎无关 | ❌ 无 |
| 120日百分位 | +0.0287 | 微弱正相关 | ❌ 无 |
| 排名变化 | -0.0123 | 几乎无关（负相关） | ❌ 无 |
| 量价共振 | +0.0031 | 微弱增益（但胜率更低） | ⚠️ 微弱但不可靠 |

### 核心结论

> **板块成交额/成交量指标没有显著的领先性。**

具体说明：

1. **板块量能无法预测ETF次日收益**：所有量能指标的领先相关系数均<0.05，无法达到有效预测水平。

2. **量价共振有微弱增益但不稳定**：板块上涨+放量时ETF次日收益比仅涨时高0.31%，但胜率反而更低（39.4% vs 46.6%）。说明少数极端大涨日拉高了平均，但大多数共振日没有带来正收益。

3. **排名变化是反向指标**：板块成交额排名上升时，ETF次日收益反而更差（-0.0061 vs +0.0082）。追热点（排名上升的板块）在次日面临回调风险。

4. **分持有期无规律**：1日无差异，3-5日放量后反而差，10日微弱优势。没有稳定的持有期规律。

5. **没有板块表现出特殊的先导价值**：即使领先相关性最高的软件ETF/云计算ETF（+0.065），也远低于有效预测所需的0.10+水平。

### 对策略设计的启示

- **不应使用板块量能作为提前入场信号**：无论是5日/20日比率、120日百分位、还是排名变化，都无法预测ETF未来收益。
- **板块量能可用于确认而非预测**：量价共振日虽然平均收益略高，但胜率更低。更适合作为"已入场后的信心增强指标"，而非"入场触发信号"。
- **板块排名变化是反向指标**：避免在板块成交额排名快速上升时追入（可能面临次日回调）。
- **与之前板块价格无领先性的结论一致**：板块价格无领先性（0.027），板块量能也无领先性。板块数据整体上不能预测ETF走势。
