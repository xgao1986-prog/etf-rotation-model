# 候选池宽度—实际仓位—后续表现 诊断报告

## 一、核心发现摘要

### 1.2 关键结论

1. **候选数量与后续市场收益呈非单调关系**：
   - 0只候选（272个周期）：策略大幅降仓（8.9%行业+18.6%防御），组合收益0.01%，基本空仓避险。对应市场状态：熊市223次、震荡28次、弱牛20次、强牛1次。硬条件正确识别了弱势市场。
   - 5只候选（120个周期）：**表现最差的区间之一**，组合收益仅0.01%，等权池-0.06%。满仓买入恰好踩在市场拐点。市场状态分布：强牛38、弱牛37、熊市37、震荡8——说明5只候选时市场状态高度混杂，硬条件无法区分好坏。
   - 6-8只候选（253个周期）：**实际最差**，组合收益-0.02%，等权池-0.05%。市场状态：弱牛94、强牛90、熊市54、震荡15。候选数量中等但市场表现差，说明硬条件筛选出的ETF质量不高。
   - 9只以上（288个周期）：表现最佳，组合收益0.17%，等权池0.19%。市场状态：强牛208、弱牛69、熊市11、震荡15。候选多确实对应强牛市场，但策略超额为-0.02%（跑输等权池）。

2. **候选少时降仓有效，但不够**：
   - 候选0-2只时，策略平均行业仓位20.2%，远低于等权池的0.05%平均收益，降仓确实避免了部分亏损
   - 但候选3-4只时行业仓位已达64.5%，接近满仓，而此时市场等权池仅0.06%收益，说明**硬条件允许了过多弱势ETF通过**
   - 0只候选时行业仓位并非0%，而是8.9%。这是因为部分日期虽然无新BUY信号，但已有持仓尚未触发SELL（均线跌破），导致 residual 行业暴露

3. **排序有效性检验（候选>5只时）**：
   - 5日：前5名均值超额 0.09%，胜率 53.6%（样本541）
   - 10日：前5名均值超额 0.52%，胜率 55.5%（样本541）
   - 20日：前5名均值超额 0.70%，胜率 57.4%（样本537）
   - 前5名 vs 行业等权池：20日超额0.26%，胜率57.4%
   - **结论**：排序区分力微弱，20日超额仅0.70%，且样本波动极大（从-12.5%到+16.5%），不具备实用价值

4. **硬条件有效性判断**：
   - 当候选0只时，等权池-0.01%（基本为0），策略成功避险
   - 当候选5只时，等权池-0.06%（显著为负），**硬条件未能过滤这5只候选**，策略仍77.3%行业仓位暴露
   - 当候选9+时，等权池+0.19%（显著为正），候选多对应好市场，但策略跑输等权池
   - **判断**：硬条件在极端情况（0候选）有效，但在中间地带（3-8候选）失效，既未充分过滤弱势，也未捕获强势

## 二、对漏斗审计的修正说明

### 2.1 阶段1最小值=0的解释
预热期（2019-06-03 至 2019-08-13）内，MA50需要50个交易日+shift(1)=51天才能首次计算。预热前所有调仓日的阶段1（成熟ETF数）均为0，因为尚无ETF满足 `history_count >= 51`。这**不是策略缺陷**，而是技术指标的固有滞后。在漏斗审计中，预热期数据应单独标注，不计入正常分析。

预热前50个调仓日，候选分布：0只=50次，1-2只=0次，3-4只=0次... 说明预热期内所有ETF均不成熟，策略处于完全空仓状态（或仅持有防御资产）。

### 2.2 11个未归类调仓日的解释
这11个日期出现在2019-06-03至2019-08-09之间，对应沪深300数据不足以计算MA20/MA50（数据起始日为2019-06-03），因此无法判断市场状态。在修正后的报告中，这些日期被标记为"未知"状态，但不影响后续分析（样本外期间无此问题）。

在预热前49个调仓日中，49个被标记为"未知"状态（因为bench MA20/MA50无法计算）。当bench数据足够后（2019-08-12之后），市场状态开始正常分类。

### 2.3 40/55门槛的含义
- **40分**：正常市场（`market_quality_median >= 0`）的评分门槛。所有通过硬条件的候选中，约81.9%的总评分>=40。
- **55分**：差市场（`market_quality_median < 0`）的评分门槛，自动提高15分以避免"矬子里拔将军"。当市场整体动量为负时，所有ETF的momentum_rank被强制设为0，此时总评分天然降低，55分门槛进一步压缩候选池。
- 从淘汰率看，40分门槛仅淘汰18.1%的候选，真正瓶颈是硬条件（`trend>=15, confirm>=4, prev_close>MA20, ma20_slope>0`）。在346个调仓日中，约60%的日期候选不足5只，说明**策略是"凑5只或空缺"，而非"优中选优"**。

## 三、建议

1. **硬条件需要重新校准**：当前硬条件允许太多弱势ETF通过（5只组满仓后市场收益为负），建议：
   - 收紧 `prev_close > MA20` 为 `prev_close > MA20 * 1.01`（要求站上均线1%以上）
   - 或收紧 `ma20_slope > 0` 为 `ma20_slope > 0.001`（要求均线有可见向上斜率）
   - 或增加 `close > MA50` 作为硬条件（而非仅用于评分）

2. **排序区分力弱**：候选>5时，评分排序对未来超额有限（20日仅0.70%，胜率57.4%），应：
   - 重新审视评分权重（趋势30%+确认20%+动量25%+成交量15%+波动率10%）
   - 考虑将动量排名从25%提高到40%或更高
   - 或引入行业相对强度（RS）作为独立因子

3. **候选数量作为独立信号**：候选数量本身可能是市场状态的领先指标：
   - 0-2候选：强制降仓至≤30%行业（当前已部分实现）
   - 3-4候选：谨慎参与，限制行业仓位≤50%
   - 5-8候选：这是**危险区间**，历史数据显示市场收益为负，建议进一步收紧条件或降低仓位
   - 9+候选：积极满仓，但需改进排序以跑赢等权池

4. **样本外验证**：以上结论基于2019-08-13至2024-09-30的全样本数据。建议在2024-01-01之后的样本外期间单独验证，以确保没有过拟合。
