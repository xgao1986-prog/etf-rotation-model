## 二、数据口径说明

| 项目 | 说明 |
|------|------|
| **指数类型** | 申万一级行业指数（价格指数） |
| **是否复权** | 否（adjust_type='none'） |
| **价格含义** | 指数点位（不含分红、派息） |
| **成交量** | 单位：亿股（板块内成分股合计） |
| **成交额** | 单位：亿元（板块内成分股合计） |
| **适用场景** | 动量/趋势计算、方向一致性判断 |
| **不适用场景** | 收益对比（需使用全收益指数） |

> **重要**: 申万指数是**价格指数**，不包含分红收益。这意味着用板块指数计算的信号可能在分红季与实际ETF收益有偏差。但由于我们只关注**方向一致性**（涨/跌），而非绝对收益，价格指数完全适用。

## 六、验证结论

### 6.1 数据质量
- ✅ 18个板块数据全部成功入库
- ✅ 数据覆盖度满足策略需求（16个板块从2019年开始，2个从2021年开始）
- ✅ 数据口径一致（均为价格指数，不复权）
- ✅ 缺失率约7.7%，符合正常交易中断预期（节假日等）

### 6.2 映射质量
- ✅ 修正后27个板块-ETF配对全部高相关（>0.7）
- ✅ 平均相关性0.935，方向一致率87.2%
- ✅ 移除了3个低相关性映射（消费ETF→家用电器、碳中和ETF→电力设备/环保）
- ✅ 5只多行业/跨境ETF标记为无映射，避免错误信号

### 6.3 板块领先性
- ⚠️ 板块指数**无显著领先性**（领先相关性0.027，几乎为零）
- ⚠️ 板块与ETF**同步变动**，而非提前变动
- **含义**: 板块数据不能用于"提前入场"，但可用于**信号确认**（如板块和ETF都发出买入信号时，增强信心）

## 七、下一步建议

### 7.1 信号合成设计（待实现）

由于板块无领先性，建议采用**"双重确认"**策略而非**"提前入场"**：

```
买入信号强度 = ETF自身动量得分 × 板块动量确认系数

其中:
- 板块动量确认系数 = 1.0 (板块和ETF同向) / 0.5 (反向) / 0.8 (板块中性)
- 仅在板块和ETF方向一致时，给予全额权重
- 方向不一致时，降低该ETF的买入优先级
```

### 7.2 待实现功能

1. **板块数据读取**: 在 `database.py` 中增加 `get_sector_data()` 方法
2. **板块动量计算**: 在 `strategy.py` 中增加板块层面的动量/趋势指标
3. **信号合成**: 在 `strategy.py` 的 `select_candidates()` 中融入板块确认系数
4. **配置参数**: 增加 `sector_confirmation` 开关和权重参数
5. **回测适配**: 修改 `backtest.py` 支持读取板块数据并打印板块信号

### 7.3 注意事项

- 石油石化(801960)和环保(801970)数据从2021-12开始，回测时需注意早期数据缺失
- 板块指数是价格指数，不包含分红，在高分红板块（如银行、煤炭）可能有偏差
- 环保板块无对应ETF，仅作为观察指标，不直接用于交易
