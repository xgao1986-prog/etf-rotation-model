## 8. B/C 结果完全相同原因分析

### 8.1 差异确实存在，但发生在被筛选掉的ETF上

- B/C vol_score 不同的记录：3,002 / 11,133 (27.0%)
- 这些差异发生在 645 / 873 个交易日 (73.9%)
- 但验证期交易序列：B=255, C=255，**完全相同**

### 8.2 根因：trend_score 过滤

- B非零但C为零的记录：3,002 / 8,652 (34.7%)
- 其中 **trend_score <= 0 的：100.0%**
- 结论：所有被C排除的高波动ETF，都因为trend_score <= 0
- 而这些ETF本来就不会进入候选（trend_score是硬筛选条件）

### 8.3 排名变化不导致入选差异

- total_score不同的记录：3,002 / 11,133 (27.0%)
- 取样100个vol_score不同的日期，前5名变化：18%
- 但这些排名变化在min_total_score过滤后未影响实际入选
- 验证期交易序列完全相同，证明B/C在实际执行中不可区分

## 9. 候选选择（修正后：vs B0.3 支配规则）

### 9.1 支配规则定义

候选在验证期必须同时满足：
1. 年化收益 >= B0.3 或至少改善
2. Sharpe >= B0.3 或至少改善
3. 最大回撤 <= B0.3（不深于基准）
4. 换手增加时必须有收益补偿
5. 至少改善收益或Sharpe之一

### 9.3 逐个淘汰说明

**方案B：高波动前20%加分**
- 验证期年化 9.35% < B0.3 13.45%（-4.10pp）
- 验证期Sharpe 0.4592 < B0.3 0.6926（-0.2334）
- 验证期回撤 -22.72% < B0.3 -17.75%（深4.97pp）
- 交易次数 255 > B0.3 232，但无收益补偿
- **结论：被B0.3全面支配，淘汰**

**方案C：高波动+趋势条件**
- 验证期表现与方案B完全相同（年化9.35%，Sharpe0.4592，回撤-22.72%）
- 被B0.3全面支配，淘汰
- 额外风险：vol_score与momentum_rank相关性+0.4644，重新引入动量暴露
- **结论：被B0.3支配，且额外引入动量风险，淘汰**

**方案D：波动率加速上升(shift1)**
- 训练期最优（11.11%），但验证期仅8.60%（-2.85pp vs B0.3）
- 验证期Sharpe 0.4201 < B0.3 0.6926（-0.2725）
- 验证期回撤 -23.60% < B0.3 -17.75%（深5.85pp）
- 交易次数 270 > B0.3 232，但无收益补偿
- 典型的训练期过拟合（训练期+1.56% vs 验证期-4.85%）
- **结论：训练期过拟合，验证期被B0.3支配，淘汰**

### 9.4 最终结论

- 训练期最优: 波动率加速上升(shift1) (年化 11.11%)
- 但训练期优势在验证期全部反转（过拟合）
- 所有实验组验证期均被B0.3支配
- **最终候选: 保持 B0.3 基准（vol_score 关闭）**
