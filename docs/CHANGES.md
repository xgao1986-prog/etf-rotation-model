## 2026-06-21（本次 - Phase 6.8 结构牛市适应性归因 v2.0 完全重写）

**问题根因：**
1. **结构牛市0个区间**：`market_df`在`load_data_from_db()`中排除了`000300.SH`，但`identify_structural_bull_periods`和`counterfactual_1`仍在已排除的`market_df`中查找`000300.SH`，找不到任何数据。
2. **5项归因强制缩放失真**：使用比例缩放使5项之和等于总超额，导致数值失真、结论颠倒（如选股从"优于随机"变成"差于随机"）。
3. **反事实1为0.00%**：同问题1，找不到沪深300价格数据。
4. **反事实2为假**：使用"等权=实际收益"（差异≈0），未使用真实评分模拟。回测输出中无法获取`signals_df`。
5. **权重反事实使用未来Top5**：之前等权top5收益使用了区间结束后才知道的Top5作为未来信息。
6. **现金拖累简单累加**：之前逐日简单累加，未用连乘计算。
7. **止损归因直接相加pnl_pct**：之前直接加每笔pnl_pct，未按持仓金额和NAV计算。
8. **连续条件按自然日**：之前`(end - start).days >= 5`，应按交易日数判断。
9. **区间统计用起点20日收益**：之前报告的是`start_ret`（起点20日滚动收益），应报告区间累计收益和平均分化度。
10. **结论含"待完成"文字**：报告中写了"待完成多区间验证后填充"，违反了"只能写已证明结论"的要求。
11. **覆盖/选股/权重概念混淆**：未严格区分"领涨方向是否在池"、"池内未选中"、"同标的不同权重"三个概念。

**修正内容：**
- 数据加载返回3个对象：`market_df`(含000300.SH)、`bench_df`(仅基准)、`industry_df`(排除基准)。`identify`用`market_df`，归因用`industry_df`。
- 五个诊断维度直接报告原始值，不强制缩放，注明"不强制加总等于总超额"。
- **现金拖累**：逐日连乘计算虚拟NAV（(1-cash)×策略收益 + cash×基准收益），不是简单累加。
- **覆盖差距**：检查市场所有ETF（不限池内），如果最领涨不在池中则差距=外部最佳-池内最佳；如果在池中则差距=0。不重复计算选股差距。
- **选股差距**：策略持仓加权平均 vs 池内最佳ETF收益。策略持仓中没有池内最佳时才是选股问题。
- **权重差距**：仅用实际入选过的标的，比较等权 vs 策略实际权重。禁止使用区间结束后才知道的Top5。
- **退出差距**：按(卖出价-买入成本)×股数计算金额PnL，除以区间开始日NAV。找到下次真实周四调仓日（必须是交易日）。
- **结构牛市定义**：连续条件按**交易日数**判断（>=5个交易日），不是自然日。报告区间累计沪深300收益和平均分化度。
- **反事实1**：逐日连乘，仅使用当日已知现金比例。
- **反事实2**：已删除。回测输出中无法可靠获取各调仓日当时可见的真实评分。
- **多区间验证**：33个结构牛市区间（训练期23个，验证期10个），全部汇总报告。
- **勾稽断言**：日期不超2024-12-31、NAV数据不少于交易日数、止损计数与trades_df一致、无未来数据。
- **报告只能写已证明结论**：删除"待完成"文字。
- **阈值解释**：明确说明不根据目标区间反向选择，20日>=0%和3%分化在多种市场环境下都有经济意义。
