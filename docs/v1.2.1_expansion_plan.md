### 1.2 核心问题

**通信ETF（515880）是牛市收益王（+363%），但持仓占比只有 22.3%**
- 而银行ETF 持仓最多（27.8%），但强牛收益只有 43%
- 这意味着：评分体系**没有识别出通信ETF的强势**，导致它买入不够

**医药ETF（512010）持仓很多（22%，397天），但强牛收益-31%**
- 说明：医药的评分信号**在牛市容易误报**，趋势分/确认分可能不够精准

## 二、实验方案

### 2.1 方向一：纳入更多概念ETF（扩大标的池）

当前16只行业ETF偏"传统行业"，缺少2023-2025年的热点概念：

| 概念方向 | 候选ETF | 为什么纳入 |
|---------|--------|----------|
| AI/算力 | 588200.SH（科创芯片ETF） | AI是2023-2025主线，与通信/半导体有差异 |
| 机器人 | 562500.SH（机器人ETF） | 机器人是新赛道，已纳入159530但范围更广 |
| 游戏/传媒 | 159869.SZ（游戏ETF） | AI应用落地最快领域，与传媒512980有差异 |
| 云计算 | 516510.SH（云计算ETF） | 算力基础设施，与通信/半导体有差异 |
| 创新药 | 159992.SZ（创新药ETF） | 医药中的成长股，与512010传统医药有差异 |
| 港股科技 | 513130.SH（港股科技ETF） | 港股估值更低，分散A股单一市场风险 |
| 红利/高股息 | 510880.SH（红利ETF） | 防御属性，熊市替代行业ETF |
| 央企/国企 | 560700.SH（央企改革ETF） | 政策主线，低估值 |

**建议第一批纳入**：
- AI算力：588200.SH（科创芯片ETF）
- 游戏/AI应用：159869.SZ（游戏ETF）
- 云计算：516510.SH（云计算ETF）
- 港股科技：513130.SH（港股科技ETF）
- 红利高股息：510880.SH（红利ETF）

这样从16只扩展到21只，增加5个新方向。

### 2.2 方向二：相关性去重（避免重复敞口）

**核心逻辑**：
1. 每天收盘后，计算所有已选ETF之间的30日滚动相关性
2. 如果相关性>0.75（阈值可调），视为"同一条线"
3. 同一条线中，只保留评分最高的1只，其余筛掉

**实现方式**：
- 在 `generate_signals()` 中，**买入阶段**加入相关性过滤
- 假设：半导体和通信都满足买入条件，但相关性0.745>0.75
- 只保留评分更高的那只，另一只放入"候选池"但不买入

**好处**：
- 避免"银行+券商"这种金融线重复
- 避免"通信+半导体"这种科技线重复
- 释放仓位给不同方向（比如科技+消费+防御），分散风险

### 2.3 方向三：优化评分体系（解决通信ETF买不够的问题）

**通信ETF牛市收益363%但持仓只有22%，为什么？**
- 可能原因1：通信ETF的波动率得分被扣分（波动率高）
- 可能原因2：通信ETF的成交量得分不够（放量不够明显）
- 可能原因3：趋势确认得分不够（连续在均线上的天数不够）

**实验方案**：
- 降低"波动率"权重（从10%降到5%），提高"动量"权重（从25%提到30%）
- 或者：在强牛状态下，放宽波动率扣分（高波动在牛市是加分项）
- 或者：增加"行业概念动量"因子（如果AI概念在涨，AI相关ETF额外加分）

## 三、实验优先级建议

### 优先级1：相关性去重（影响最大，改动最小）
- 不改评分体系，不改标的池
- 只在买入时加一层过滤
- 回测基线应该变化，但能验证"是否真的避免重复敞口"

### 优先级2：纳入5只概念ETF（扩展标的池）
- 需要新增数据下载（iFinD/Kimi帮你获取）
- 回测基线会变（因为标的不一样），但可以做"对比实验"
- 建议：先跑21只 vs 16只的对比回测，看收益/回撤/夏普是否提升

### 优先级3：评分权重优化（解决通信ETF买不够）
- 在优先级2完成后，如果收益仍不理想，再调权重
- 或者：先分析通信ETF的得分结构（趋势/确认/动量/成交量/波动率各得多少分），找出瓶颈
