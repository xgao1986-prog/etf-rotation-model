## 关键参数

### 1. 相关性阈值
- 默认值：0.75
- 含义：两只ETF日收益率相关性>0.75，视为"同一条线"
- 只剔除被选中者的高相关ETF，不剔除与被选中者无关的ETF

### 2. 核心池范围
- 当前：16只行业ETF
- 新增：5只概念ETF（AI芯片、游戏、云计算、港股科技、红利）
- 合计：21只

### 3. 备选池触发条件
- 核心池选中数量 < 5只
- 剩余仓位 = 5 - 核心池选中数
- 先用宽基补仓（补足股票敞口）
- 宽基也不够再用防御

## 实现要点

### 1. 评分统一
- 所有21只核心池ETF使用同一套评分
- 全部参与横截面动量排名
- 无简化评分（当前宽基/防御的简化评分取消）

### 2. 买入流程修改

```python
def select_positions(scores_df, regime_id, constraints):
    """
    1. 所有核心池ETF按总分排序
    2. 逐个遍历：
       a. 如果与已选ETF相关性>0.75，跳过
       b. 如果符合状态上限（如强牛防御上限），保留
       c. 选中
    3. 如果选中<5只，用备选池补充
    """
    selected = []
    candidates = scores_df.sort_values('total_score', ascending=False)
    
    for _, row in candidates.iterrows():
        if len(selected) >= 5:
            break
        
        ticker = row['ticker']
        
        # 检查相关性：与已选ETF的相关性
        should_skip = False
        for s in selected:
            corr = get_correlation(ticker, s['ticker'])
            if corr > 0.75:
                should_skip = True
                break
        
        if should_skip:
            continue
        
        # 检查状态上限
        if not check_regime_constraint(ticker, regime_id, constraints):
            continue
        
        selected.append(row)
    
    # 补充备选池
    if len(selected) < 5:
        selected += fill_fallback(selected, regime_id, constraints)
    
    return selected
```

### 3. 备选池保留简化评分

宽基和防御仍然用简化评分（不参与核心池排名），只在兜底时用：
- 宽基：趋势+确认，门槛25分
- 防御：趋势+确认，门槛30分

### 4. 状态上限仍然生效

即使统一排序，状态上限防止方向错误：
- 强牛：防御上限0%，宽基上限20%
- 弱牛：防御上限10%，宽基上限20%
- 震荡：防御上限20%，宽基上限20%
- 熊市：防御上限40%，宽基上限20%
