## 1. 问题陈述

### 1.1 v1.1 已验证的问题

| 问题 | 实验证据 | 影响 |
|------|----------|------|
| **结构性牛市跑输** | 2019-2021 年策略收益 +7%，沪深 300 +36% | 最大痛点：策略在趋势明确的市场中无法捕捉行业机会 |
| **宽基模块负贡献** | 开启后收益 -11.7%（104.76% → 93.08%），回撤 +4%（-14.41% → -18.48%） | 触发条件太松（82.3% 调仓日触发），频繁追涨弱势反弹 |
| **行业信号不足** | 牛市中行业 ETF 评分 ≥ 40 的仅 2-3 只，无法填满 75% 仓位 | 入场阈值太严格（`min_total_score=40`），在趋势确认阶段就错过机会 |
| **防御填充过度** | 牛市中 30% 防御填充导致策略 beta 不足（0.42 vs 沪深 300 的 1.0） | 防御资产在强市中拖累收益，但无填充时收益腰斩（50% vs 104.76%） |
| **单维度大盘择时** | 2-state（MA50 斜率正负）过于粗糙，默认关闭反而更优 | 无法区分"牛市初期"、"牛市中期"、"牛市后期"、"震荡市"等细粒度状态 |

### 1.2 根因分析

**核心问题：行业ETF评分系统与真实市场状态脱节**

v1.1 的评分体系（趋势30 + 确认20 + 动量25 + 成交量15 + 波动率10）是基于**单只ETF的个体行为**设计的，没有考虑**板块层面的宏观信号**。这导致：

1. **结构性牛市**（如 2019-2021 科技/医药/消费）中，行业ETF本身动量不够强（横截面排名需要至少3-5只同时强势），但板块指数可能已提前数月进入趋势。
2. **宽基补仓**被设计成"行业不足时补宽基"，但触发条件（`bull_market=True` + `prev_close > MA20 * 0.98`）太松，导致在弱势反弹中频繁触发。
3. **防御填充**是双刃剑：没有填充时现金闲置（收益50%），30%填充时强市中防御占比过高（30%是慢钱），导致 beta 不足。

**结论**：需要引入**市场状态（Market Regime）检测**和**板块信号增强**两个维度。

## 3. 设计方案

### 3.1 市场状态检测（Market Regime Detection）

#### 3.1.1 当前问题：2-state 过于粗糙

v1.1 的 `market_timing()` 使用 `ma50_slope` 的符号（>0 或 <0）作为唯一状态：
- 正 → 满仓（100%）
- 负 → 半仓（50%）

实验验证：默认关闭（`market_timing=False`）反而更优，因为 2-state 无法区分：
- 牛市初期（MA50 刚拐头，趋势未确认）
- 牛市中期（MA50 加速向上，确认）
- 牛市后期（MA50 斜率放缓，但仍正）
- 震荡市（MA50 附近波动，无明确方向）
- 熊市初期（MA50 刚拐头向下）
- 熊市中期（MA50 加速向下）

#### 3.1.2 新方案：4-state 市场状态机

基于以下指标综合判定：

| 指标 | 来源 | 计算方式 | 用途 |
|------|------|----------|------|
| 沪深300 相对 MA50 位置 | 收盘价 / MA50 | 高于 1.02 为强势 | 趋势方向 |
| 沪深300 相对 MA20 位置 | 收盘价 / MA20 | 高于 1.01 为短期强势 | 短期动量 |
| MA50 斜率变化 | MA50_slope(t) / MA50_slope(t-20) | 斜率加速/减速 | 趋势强度 |
| 20日波动率 | 20日收盘价标准差 / 均值 | < 0.015 为低波动，> 0.025 为高波动 | 波动率状态 |
| 市场宽度（可选） | 行业ETF中收盘价 > MA50 的比例 | > 0.6 为普涨 | 市场广度 |

**状态定义**：

| 状态 | 条件 | 名称 | 仓位指导 |
|------|------|------|----------|
| 1 | 沪深300 > MA50 × 1.02 AND MA50斜率加速 AND 波动率适中 | **强牛** | 满仓（100%），防御填充降至 0% |
| 2 | 沪深300 > MA50 × 1.02 BUT MA50斜率减速 OR 波动率偏高 | **弱牛** | 满仓（100%），防御填充降至 15% |
| 3 | 沪深300 在 MA20 和 MA50 之间 OR 波动率偏低 | **震荡** | 默认（75% + 30% 填充），降低入场门槛到 35 |
| 4 | 沪深300 < MA50 × 0.98 AND MA50斜率加速向下 | **熊市** | 半仓（50%），防御填充升至 50%，提高止损到 -12% |

**状态切换规则**：
- 状态切换需要连续 5 个交易日满足条件（避免噪声）
- 状态切换时触发策略参数动态调整（不单独调仓，而是周五调仓时一并应用）

#### 3.1.3 状态检测代码设计

```python
# 伪代码（待实现）
class MarketRegimeDetector:
    def __init__(self, lookback=20):
        self.lookback = lookback
        self.state_history = []
    
    def detect(self, market_df):
        """
        输入: 沪深300日K数据（含close, ma20, ma50, ma20_slope, ma50_slope）
        输出: 状态编码 (1=强牛, 2=弱牛, 3=震荡, 4=熊市)
        """
        close = market_df['close'].iloc[-1]
        ma50 = market_df['ma50'].iloc[-1]
        ma50_slope = market_df['ma50_slope'].iloc[-1]
        ma50_slope_prev = market_df['ma50_slope'].iloc[-20]
        vol_20 = market_df['close'].iloc[-20:].std() / market_df['close'].iloc[-20:].mean()
        
        # 1. 趋势位置
        trend_position = close / ma50
        # 2. 斜率变化
        slope_accel = ma50_slope / ma50_slope_prev if ma50_slope_prev != 0 else 1.0
        # 3. 波动率
        vol_regime = 'low' if vol_20 < 0.015 else 'high' if vol_20 > 0.025 else 'med'
        
        # 状态判定
        if trend_position > 1.02 and ma50_slope > 0 and slope_accel > 1.0 and vol_regime == 'med':
            new_state = 1  # 强牛
        elif trend_position > 1.02 and ma50_slope > 0 and (slope_accel <= 1.0 or vol_regime in ['high', 'low']):
            new_state = 2  # 弱牛
        elif trend_position > 0.98 and ma50_slope > -0.001:
            new_state = 3  # 震荡
        else:
            new_state = 4  # 熊市
        
        # 连续确认
        self.state_history.append(new_state)
        if len(self.state_history) > 5:
            self.state_history.pop(0)
        
        # 需要连续 5 天一致才确认
        if len(self.state_history) == 5 and len(set(self.state_history)) == 1:
            return self.state_history[0]
        return self.current_state  # 返回上一个确认状态
```

### 3.2 板块数据增强（Sector Signal Boost）

#### 3.2.1 当前问题：无板块信号

v1.1 的评分完全基于单只ETF的个体行为。行业ETF（如 512480.SH 半导体）虽然跟踪某个板块，但评分没有利用板块指数本身的动量信息。

**问题场景**：
- 半导体板块指数（申万半导体）已进入上升趋势，但 512480.SH 的横截面动量排名不够高（因为同期其他板块也在涨），导致评分 < 40，不买入。
- 当板块指数确认趋势后，ETF通常已经滞后 1-2 周。

```python
def boost_sector_score(etf_score, sector_index_data):
    """
    如果板块指数确认趋势，给 ETF 评分加 bonus
    """
    sector_ma20 = sector_index_data['close'].rolling(20).mean().iloc[-1]
    sector_ma50 = sector_index_data['close'].rolling(50).mean().iloc[-1]
    sector_close = sector_index_data['close'].iloc[-1]
    sector_ma20_slope = calculate_slope(sector_index_data['close'], 20)
    
    bonus = 0
    # 板块指数确认强势
    if sector_close > sector_ma20 and sector_close > sector_ma50 and sector_ma20_slope > 0:
        bonus += 10  # 板块趋势确认 +10
    # 板块指数加速
    if sector_close > sector_ma20 * 1.02 and sector_ma20_slope > sector_ma20_slope.shift(20) * 1.0:
        bonus += 5  # 板块加速 +5
    
    # 上限：bonus 不超过 15，总评分不超过 100
    return min(100, etf_score + min(15, bonus))
```

### 3.3 宽基重新启用（Wide-Base Re-enable）

#### 3.3.1 当前问题：触发条件太松

v1.1 的宽基触发条件：
- `total_score >= 25`（太松，横截面不排名的情况下，25分很容易达到）
- `prev_close > ma20 * 0.98`（几乎无门槛）
- `ma20_slope > -0.01`（几乎无门槛）
- `bull_market=True`（大盘 > MA50，但 82.3% 的调仓日满足）

结果：107 次宽基买入，94 次卖出，频繁追涨弱势反弹，拖累回撤。

#### 3.3.2 新方案：三重收紧 + 市场状态联动

**收紧条件**：

| 条件 | v1.1 旧值 | v1.2 新值 | 理由 |
|------|----------|----------|------|
| 总评分门槛 | ≥ 25 | ≥ **35** | 提高到中等门槛，避免垃圾信号 |
| 收盘价条件 | > MA20 × 0.98 | > MA20 × **1.0** | 必须真正站上均线 |
| 均线斜率 | > -0.01 | > **0.005** | 要求趋势正在向上 |
| 市场状态要求 | `bull_market=True` | **强牛或弱牛**（状态 1 或 2） | 只在明确牛市中启用 |
| 最小持有周期 | 无 | **14天** | 避免频繁交易，减少换手率 |
| 最大宽基仓位 | 无限制 | **20%**（最多 1 只） | 限制为补充而非主力 |

**持有周期逻辑**：
- 宽基买入后，至少持有 14 天（约 3 周），即使评分跌破门槛也不卖出
- 14 天后，按正常出场条件检查（跌破 MA20 或止损）
- 这避免了弱势反弹中的频繁进出

### 3.4 动态参数调整（Parameter Mapping）

v1.2 的核心创新：**根据市场状态动态调整策略参数**。

#### 3.4.1 参数映射表

| 参数 | 状态 1 强牛 | 状态 2 弱牛 | 状态 3 震荡 | 状态 4 熊市 |
|------|------------|------------|------------|------------|
| `min_total_score` | 35 | 35 | 40 | 45 |
| `defense_fill_max_ratio_bull` | 0% | 15% | 30% | 50% |
| `max_position_per_etf` | 20% | 18% | 15% | 12% |
| `stop_loss` | -10% | -8% | -8% | -12% |
| `trailing_stop_mode` | standard | tiered | tiered | standard |
| `fallback_equity_enabled` | True | True | False | False |
| `fallback_equity_min_score` | 35 | 35 | 25 | 25 |
| `cooling_period_days` | 3 | 5 | 5 | 7 |

**逻辑说明**：
- **强牛**：降低门槛（35）让更多行业进入，关闭防御填充（0%），允许宽基（20%上限），更松止损（-10%），更短冷静期（3天）

- **熊市**：提高门槛（45），增加防御（50%），降低单只上限（12%），更紧止损（-12%），标准追踪止损，更长冷静期（7天）

## 5. 实验计划

### 5.1 实验 1：市场状态检测准确性

**目标**：验证 4-state 检测的历史准确性

**方法**：
- 回测 2019-2026 全区间，记录每日状态
- 人工标注 2019-2021 的关键时间段（牛市初期/中期/后期）
- 对比检测状态与人工标注的混淆矩阵

**验收标准**：
- 状态切换延迟 ≤ 5 天（从真实状态变化到检测出变化）
- 强牛状态覆盖率 ≥ 60%（牛市中至少 60% 时间被检测为强牛/弱牛）
- 误报率 ≤ 20%（熊市中检测为强牛的比例）

### 5.2 实验 2：板块加成效果

**目标**：验证板块加成对行业信号的提升

**方法**：
- 对比：无板块加成（v1.1） vs 有板块加成（v1.2）
- 记录：2019-2021 中行业信号数量、评分分布、买入触发次数

**验收标准**：
- 2019-2021 行业买入次数增加 ≥ 20%（从 269 次增加到 ≥ 323 次）
- 2019-2021 总收益 ≥ 25%（当前仅 7%）
- 板块加成不增加误报（额外买入的胜率 ≥ 40%）

### 5.3 实验 3：宽基重新启用

**目标**：验证收紧后的宽基条件是否正贡献

**方法**：
- 对比：v1.1 宽基（默认关闭） vs v1.2 宽基（强牛/弱牛时开启，条件收紧）
- 记录：宽基买入次数、持有周期、收益贡献

**验收标准**：
- 宽基买入次数 ≤ 30（vs v1.1 的 107 次）
- 宽基持有周期 ≥ 14 天（平均）
- 开启后总收益 ≥ 104.76%（不低于当前默认）
- 开启后最大回撤 ≤ -15%（不恶化太多）

### 5.4 实验 4：全参数组合（v1.2 完整版）

**目标**：验证所有改动一起工作的效果

**方法**：
- 全区间回测（2019-2026）
- 对比：v1.1 默认 vs v1.2 完整

**验收标准**：
- 总收益 ≥ 110%（比 v1.1 的 104.76% 更高）
- 夏普 ≥ 0.85（比 v1.1 的 0.78 更高）
- 最大回撤 ≤ -12%（比 v1.1 的 -14.41% 更低）
- 结构性牛市（2019-2021）收益 ≥ 25%（vs 当前 7%）

### 5.5 实验 5：各状态参数单独验证

**目标**：验证每个状态的参数映射是否最优

**方法**：
- 固定状态（不切换），分别测试每个状态的参数组合
- 记录：固定为强牛/弱牛/震荡/熊市时的表现

**验收标准**：
- 固定强牛时收益 ≥ 150%（高 beta 策略）
- 固定熊市时收益 ≥ 0%（正收益或低回撤）
- 固定震荡时收益 ≥ 60%（比 v1.1 的 50% 好）

## 6. 风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| 板块指数数据获取失败 | 中 | 高 | 保留 v1.1 无加成路径（`sector_boost_enabled=False` 时正常回退） |
| 市场状态检测过拟合 | 中 | 高 | 用样本外验证（2024-2026），不在 2019-2023 上优化参数 |
| 参数映射表过拟合 | 高 | 高 | 每个状态参数用独立实验验证，不组合优化 |
| 状态切换延迟导致错过趋势 | 中 | 中 | 5 天确认期可配置（实验 1 中测试 3/5/7/10 天） |
| 代码复杂度增加 | 高 | 低 | 模块化设计（market_regime.py 独立），保持可测试性 |
| 宽基持有周期导致止损不及时 | 低 | 高 | 硬止损（-8%）始终生效，14 天最小周期仅影响信号出场 |

### 9.2 术语表

| 术语 | 定义 |
|------|------|
| 市场状态（Market Regime） | 大盘当前所处的宏观环境（强牛/弱牛/震荡/熊市） |
| 板块加成（Sector Boost） | 基于板块指数动量给行业ETF评分增加的 bonus |
| 防御填充（Defense Fill） | 当行业ETF信号不足时，用防御资产（黄金/国债）填充剩余仓位 |
| 宽基补仓（Fallback Equity） | 当行业ETF信号不足时，用宽基ETF（沪深300/中证500等）作为补充 |
| 结构性牛市 | 少数行业持续强势、多数行业平庸的市场环境（如 2019-2021 科技/医药） |
| 横截面动量 | 同一时刻所有标的之间的相对动量排名（vs 时间序列动量） |
| 等权分配 | 买入时将可用资金平均分配给所有入选标的 |
