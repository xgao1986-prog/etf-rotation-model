# 数据口径说明文档

## 复权价格口径

### 1. 数据源与复权类型

| 数据源 | 复权类型 | 标记 | 说明 |
|--------|----------|------|------|
| AKShare | 前复权 (qfq) | `qfq` | `fund_etf_hist_em(adjust='qfq')` |
| iFinD / stock_finance_data | 前复权 (forward) | `forward` | `stock_finance_data_get_price(adjust='forward')` |
| EastMoney | 前复权 (qfq) | `qfq` | 默认前复权 |

### 2. 关键确认

**所有数据都是前复权价格。**

- `open` / `high` / `low` / `close` 均为复权后的价格
- `adj_close` 字段当前等于 `close`（因为 close 已经是复权价格）
- `adjust_type` 字段标记复权类型（`qfq` 或 `forward`）

### 3. 回测使用字段

| 用途 | 字段 | 说明 |
|------|------|------|
| 交易价格（买入/卖出） | `open` | 开盘价，已复权 |
| 净值计算（持仓市值） | `close` | 收盘价，已复权 |
| 信号计算（均线/动量） | `close` | 收盘价，已复权 |

### 4. 分红处理方式

**分红通过复权价格隐含处理。**

- 不需要单独处理现金分红入账
- 前复权价格已经隐含了分红、拆股等权益调整
- 回测净值计算直接基于复权价格

### 5. 注意事项

- 数据库中 `source` 字段标记数据来源
- 数据库中 `adjust_type` 字段标记复权类型
- 所有数据源统一使用前复权，确保口径一致
- 如果未来需要原始未复权价格，需要单独下载 `adjust='none'` 数据
